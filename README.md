# Casa Xololo

Sitio web bilingüe de Casa Xololo, Arroyo Cruz, Oaxaca. La web se publica desde [`site/`](site/) en GitHub Pages mediante [el flujo de despliegue](.github/workflows/pages.yml).

**URL prevista:** https://bravvess.github.io/CasaXololoSM/

La carpeta `site/` es estática: HTML, CSS, JavaScript y fotografías. No necesita compilación. Para revisarla localmente, ejecuta `python3 -m http.server 8080 --directory site` y abre `http://localhost:8080`.

El WhatsApp de reservas, el correo y la cuenta de Instagram figuran en [`site/js/config.js`](site/js/config.js) y en los enlaces visibles del sitio. Para modificar contenidos o imágenes, lee [`site/README.md`](site/README.md).

Las fotografías y el logo se proporcionaron para este proyecto.
